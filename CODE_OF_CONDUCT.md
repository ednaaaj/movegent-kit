# Code of Conduct

We want agent-kit to be a place where people can ask questions, report problems and send changes without
being treated badly.

## Expected behaviour

- Be respectful. Disagree with the idea, not the person.
- Assume good intent, and ask when something is unclear.
- Give specific, useful feedback. Take feedback the same way.
- Keep issues and pull requests about the project.

## Not acceptable

- Harassment, insults, discrimination or personal attacks.
- Publishing someone else's private information, including keys, tokens, internal IDs or chat IDs.
- Spam, or repeatedly pushing a change after a maintainer has said no.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat
offenders. To report a problem, open a private security advisory on the GitHub repository
(Security tab, "Report a vulnerability") and say it is a conduct report.

This is a short original statement. It applies to the repository, its issues and its pull requests.
